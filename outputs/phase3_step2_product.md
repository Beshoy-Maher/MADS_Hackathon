# ReleaseKit

a changelog and release-notes toolkit for small software teams

## Quick start

1. Read the module that matches your problem.
2. Copy its template.
3. Work through the checklist.
4. Keep the filled template next to your project.
5. Repeat it next time.

## Module 1: JWT.io v2 Changelog

Why this module exists: https://github.com/jsonwebtoken/jsonwebtoken.github.io/issues/723

### Checklist
- [ ] Write down the exact situation where the problem happens
- [ ] List what you do today, step by step
- [ ] Mark the step that wastes the most time
- [ ] Apply the template below to that step
- [ ] Note what changed after one week

### Template
```
Situation:
Current steps:
Slowest step:
New step:
Result after one week:
```
