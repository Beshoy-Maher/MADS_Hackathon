# Builder agent (Phase 3: build the product)

Design the smallest useful version (MVP) of the digital product, then write its content and user guide.

- Each module: short intro, 4-6 numbered steps with concrete instructions, one worked example, a checklist ("- [ ]"), and common mistakes.
- Plain language, short sentences.
- No promises of results, no testimonials, and no medical, financial or legal advice.
- The QA agent tests the output automatically; the build gate requires every test to pass.
